# Top-Down Pixel-Art Asset Cookbook

Free, permissively-licensed, top-down (3/4 JRPG/Zelda-style) tilesets and sprites
for a web pixel RPG. Every asset gets palette-remapped to the game's 16-color
palette, so style mismatch is acceptable; **license and tile quality are the
selection criteria**.

All URLs verified **2026-07-05** by fetching the page. Licenses quoted from the
pack's own page. VERIFIED = license text seen on the page today. UNVERIFIED =
claim exists but the binding text could not be confirmed on-page.

**Legend of the two clauses that matter for us:**
- *In-game use* — shipping the tiles inside the web game (all main-list packs allow this, commercially).
- *Redistribution* — re-sharing the pack files themselves, e.g. committing raw
  assets to a PUBLIC repo. CC0/CC-BY packs allow it; several "commercial-OK"
  itch packs forbid it. Flagged per pack below.

## 3. "Free AI-generated assets" reality check

Sites found advertising free AI game assets: SEELE AI (seeles.ai — "free
commercial license included," no login), PixelLab (pixellab.ai — free trial 40
generations then 5/day at ≤200x200; "commercial licensing included with all
paid plans"), PixelForge (3 free images/day; commercial license only on the
$4.99/mo Pro tier), Imagine.art, Pixelcut, PixelBox/llamagen.ai ("100%
royalty-free... no attribution").

Verification attempt: fetched pixellab.ai directly — **the homepage contains no
explicit ownership/licensing statement**; terms live behind pricing/ToS pages.
The "commercial license included" lines above are the sites' own marketing
claims, not quoted license text. UNVERIFIED across the board.

**Verdict — avoid for this project:**
1. **Copyright vacuum**: under current US Copyright Office guidance, purely
   AI-generated images are not copyrightable — the site cannot actually grant
   you an exclusive license to something nobody owns, and you can't stop
   anyone from lifting "your" assets either.
2. **Provenance/training-data risk** is unresolvable from the buyer's side; a
   trust-critical Indonesian civic-adjacent dev shipping commercially wants
   receipts, and these have none.
3. **Disclosure duty**: itch.io requires flagging assets/games made with
   generative AI; some jams and storefronts exclude them.
4. **It's unnecessary**: the CC0 haul above (Kenney ~3,300 tiles + Ninja
   Adventure + OGA packs) already covers every biome, license-clean.
   If AI is used at all, use it as a *sketch reference* you redraw, not as
   shipped pixels.

## 4. Tilemap format notes (ingest = PNG spritesheet → palette remap)

| Pack | Tile size | Ships as | Remap notes |
|---|---|---|---|
| Ninja Adventure | 16x16 | ZIP of PNG sheets + Godot demo | Autotile-organized floors; small palettes per sheet — remaps cleanly |
| Kenney Roguelike/RPG | 16x16 | ZIP, one big PNG spritesheet (~1,700 tiles) | 1px spacing variant included in Kenney sheets — check margin/spacing when slicing |
| Kenney RPG Urban | 16x16 | ZIP/PNG, 480 tiles + chars | Same Kenney sheet conventions |
| Kenney Roguelike Modern City | 16x16 | ZIP/PNG, 1,036 tiles | Same |
| Kenney Tiny Town | 16x16 | ZIP/PNG, 130 tiles | Tiny palette already — near-trivial remap |
| Kenney Roguelike Indoors | 16x16 | ZIP/PNG | Same |
| Serene Village Revamped | 16x16 | PNG sheets (+ animated objects as frame strips) | CC-BY: add LimeZu to credits |
| Zelda-like (ArMM1998) | 16x16 | gfx.zip of PNGs | GB-like low color count — remaps perfectly |
| Farming crops 16x16 | 16x16 | ZIP, PNG (crops as 5-frame growth strips) | Overlay sprites, not ground tiles |
| Beach tileset (OGA) | 16x16 | single PNG | Direct |
| Seasons of Forest sample | 16x16 | ZIP PNG + Godot tileset defs | Direct |
| Cainos Top Down Basic | **32x32** | Unity package + separate PNG textures | 2x grid: downscale 50% nearest-neighbor or use as 2x2-tile props; shadows ship separate (nice for remap) |
| PIPOYA characters | **32x32** | PNG spritesheets | Scale choice: 2x-size NPCs or downscale |
| LimeZu Modern Interiors (paid) | 16/32/48 | PNG sheets, all three sizes shipped | Use the 16x16 export; heavier palette — remap needs a good quantizer |

Pipeline implications: everything is plain PNG (no proprietary formats);
standardize on a 16x16 grid, write one slicer that takes (sheet, tile, margin,
spacing), and run the 16-color remap per-sheet. Kenney + OGA + Ninja Adventure
can live in the repo; Cainos/PIPOYA/LimeZu must be fetched at build time or
kept in a private assets store (no-redistribution clauses).

## 5. DO-NOT-USE list (as free downloads, for a commercial web game)

1. **Sprout Lands Basic (free) — Cup Nooble** — https://cupnooble.itch.io/sprout-lands-asset-pack
   Quoted from page: *"This asset pack can be used in any non-commercial

   non-commercial only.** (Premium $3.99 allows commercial, still
   no-redistribution.) Popular in tutorials — do not be fooled by "free."
2. **Pixel Crawler / "Free Pixel Art Asset Pack - Topdown" — Anokolisa** —
   https://anokolisa.itch.io/free-pixel-art-asset-pack-topdown-tileset-rpg-16x16-sprites
   License is NOT on the page — it points to a Google Drive "Terms" document.
   "Permanently free" ≠ a license. **UNVERIFIED → do not use until the Drive
   terms are read and archived.**
3. **LimeZu Modern Interiors FREE version** — https://limezu.itch.io/moderninteriors
   Free-version license terms are not stated on the page (only the paid
   version's are). → Don't ship the free ZIP; pay the $1.50 for the licensed
   full pack instead.
4. **General rule observed while surveying**: many top itch "free" packs
   (Mystic Woods, various Anokolisa/large bundles) split free/premium with
   non-commercial or unstated free tiers — always find the quoted license ON
   the page before downloading.

Also caveat-flagged (usable in-game, but **never in a public repo**): Cainos
Top Down Basic, PIPOYA characters, LimeZu paid packs — all carry
no-redistribution clauses.

## 9. Tooling for the agent-built-worlds engine

**Embeddable JS pixel-art editor: build-vs-buy verdict — BUILD (keep ours).**
There is no maintained, embeddable, MIT-ish canvas pixel-editor *library*.
What exists: Piskel (https://github.com/piskelapp/piskel) — VERIFIED
**"Licensed under the Apache License, Version 2.0"**, but it's a standalone
app (12.6k stars, last release Nov 2018), not a component; embedding means
adopting a dead app's whole build. Everything else is toy repos or apps
(Pixellate PWA, Pixelorama = Godot desktop app). A 16-color 16x16 grid editor
is ~200 lines of vanilla canvas we fully control — cheaper than any
integration. (Reference if wanted: Eloquent JavaScript ch.19 builds exactly
this, https://eloquentjavascript.net/19_paint.html.)

**Universal LPC Spritesheet Generator: verdict — SKIP for NonaFiksi.**
https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator
(old sanderfrenken repo redirects here). VERIFIED from README: code is
**GPL-3.0**; assets are per-layer under **"CC0 / CC-BY-SA 4.0 (requires
crediting authors and distributing derivatives under the same license) /
CC-BY 4.0 / OGA-BY / GPL 3.0 (requires distributing modifications under GPL
3.0 or later)"**, and *"When using generated sprites, you must credit all
non-CC0 authors"* (tool exports a credits CSV; repo ships CREDITS.csv). Two
kill factors for us: (1) most good layers are CC-BY-SA/GPL — ShareAlike
virality lands on our remapped sprites; (2) LPC bases are 64x64 walk-cycle
sheets — 4x our 16px grid, wrong silhouette. Ninja Adventure's 50+ CC0
characters + its blank template already solve NPC variety at the right size.
No CC0-only layered 16px character generator was found today.

**rot.js: verdict — DON'T ADOPT (wrong genre fit).**
https://github.com/ondras/rot.js — VERIFIED **"BSD-3-Clause license"**.
Map gen (dungeons/cellular), FOV, pathfinding, scheduling; self-described
feature-complete, last tagged release 2014-era, bugfix-only. License is
clean, but it's dungeon-crawler-shaped; our overworld kampung/sawah layouts
share none of its generators. If we ever add caves (Papua karst?), steal its
cellular-automata idea, not the dependency.

**Wave-function collapse: verdict — ADOPT kchapelier/wavefunctioncollapse as
the optional "organic terrain" brain; keep the 300-line vanilla engine as the
spine.** https://github.com/kchapelier/wavefunctioncollapse — VERIFIED **"MIT
license"**, browser-ready, OverlappingModel (learn from an example map
image — i.e., an agent draws a 32x32 sample kampung, WFC extrapolates
infinite variations) + SimpleTiledModel (explicit tile adjacency). v2.1.0
(2021) — stable-old, algorithm doesn't rot. This is the one library that
buys something our engine can't cheaply do. Alternatives: mxgmn's original
is C#; ndwfc (LingDong) unverified license today. (npmjs.com 403'd our
fetcher; license verified from the GitHub repo.)

**Autotiling/Wang tiles: verdict — stay vanilla.** No JS library worth the
dependency surfaced; 4-bit/8-bit bitmask autotiling is ~50 lines and we
already have it. WFC (above) covers the fancy case.
